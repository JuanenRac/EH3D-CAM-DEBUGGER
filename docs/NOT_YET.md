# EH3D-CAM-DEBUGGER: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Removal of material in 3D | It needs a model of the stock and a view in three dimensions; today the path is drawn from above | the window of the suite shows a part in 3D and can be called with a program |
| Clamps taken from the project of the job | Today they are boxes described by hand, one to a line | the project of the job says where its clamps are |
| Findings in the language of the window | The texts come from the library in English; the code of each finding is stable | the library gives a code and the values and the window says the sentence |
| The time compared with a real controller | The time is an upper bound; a real controller does not stop between moves | a program is run on a machine and the time is measured |
| A check of the tool and its length | The reader knows the tools but the program has no table of lengths to test against | the tool table of the suite is read here |
| Cutter compensation and canned cycles | They are reported as something the reader could not understand, never as clean | the reader of the suite expands them |
